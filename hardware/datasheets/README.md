## RTL8211F reference schematic availability

Realtek produced a separate two-page document titled *RTL8211F(D)(I) UTP <=> RGMII QFN-40 Pin Reference Schematic*, revision 1.02, dated December 24, 2015. Only third-party, download-gated copies or previews were located ([Scribd](https://www.scribd.com/document/476204953/RTL8211F-schematic), [Renrendoc](https://www.renrendoc.com/p-24612131.html), and [CSDN](https://download.csdn.net/download/weixin_43067187/83248252)); no stable, authorized Realtek-hosted PDF URL was established. It is therefore not copied into this directory. Obtain the current reference schematic directly from Realtek before release rather than relying on a reconstructed preview.

## Verification

- `Efinix_Ti60_Datasheet_v3.7.pdf`: official Efinix Ti60 family data sheet, version 3.7, October 2025, 93 pages. It covers the F225 package and C4 speed grade used by TI60F225C4.
- `Winbond_W25Q128JW_Datasheet_RevI.pdf`: official W25Q128JW data sheet, revision I, May 26, 2026, 79 pages. Its ordering table explicitly lists W25Q128JWPIQ and its WSON-8 6 x 5 mm package code P.
- `OV9281.pdf`: OMNIVISION OV9281 preliminary specification, version 1.53, January 2019, 135 pages. Its ordering information lists OV09281-H64A in a 64-pin CSP. The local file is marked proprietary; a public URL for this exact full specification was not established, so the manufacturer product page and public product brief are linked above.
- `Realtek_RTL8211F-CG_Datasheet_Rev1.4.pdf`: exact LCSC-hosted Realtek RTL8211F(D)(I)-CG data sheet, revision 1.4, November 17, 2014, 69 PDF pages. The ordering table explicitly lists RTL8211F-CG as the switching-regulator, 40-pin QFN model; the recommended operating-conditions table specifies 0 to +70 °C ambient for RTL8211F/RTL8211FD. The cover marks this full data sheet “Not for Public Release” and confidential to development partners.
- `TI_TPS563208_Datasheet.pdf`: official Texas Instruments TPS563201/TPS563208 data sheet, revision B, September 2024, 30 PDF pages. Its orderable addendum lists TPS563208DDCR as an active, production 3000-piece tape-and-reel part in the 6-pin DDC (SOT-23-Thin) package, rated for -40 to +125 °C junction temperature.
- `TI_TLV758P_Datasheet.pdf`: official Texas Instruments TLV758P data sheet, revision D, October 2023, 37 PDF pages. Its orderable addendum lists TLV75801PDBVR as an active, production 3000-piece tape-and-reel part in the 5-pin DBV (SOT-23) package, rated for -40 to +125 °C junction temperature.
- `Skyworks_Si3404_Datasheet.pdf`: official Skyworks Si3404 data sheet, 26 PDF pages. It covers the Si3404-A-GM electrical device used by the tape-and-reel SI3404-A-GMR ordering code and specifies the extended -40 to +85 °C ambient range.
- `Skyworks_UG324_Si3404_Buck_EVB.pdf`: official Skyworks UG324 non-isolated buck evaluation-board guide, April 2026, 66 PDF pages. The implemented PoE stage follows its 12 V, Class-3 topology and programming targets while using nearby fee-free 0402 resistor values where requested; it omits the jack, magnetics, indicators, test points, and optional EMI parts requested for this project.
- `Skyworks_AN1130_Si3404_Design_Guide.pdf`: official Skyworks AN1130 Si3404/06x PoE-PD controller design guide, 54 PDF pages. It documents the non-isolated buck topology, Class-3 limits, sizing equations, layout guidance, and the required separation between VNEG/VSS and board GND.
